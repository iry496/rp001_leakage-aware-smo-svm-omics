Reproducibility controls

- GEO samples are sorted by accession ID before seeded folds are created.
- pROC direction is fixed a priori (RD control, pCR case, increasing pCR score).
- Supervised preprocessing, feature selection, cost tuning, and class weighting in the guarded workflow are confined to training partitions.
- External labels are used only for final evaluation; feature sets, scaling, model parameters, and decision rules are frozen before projection.
- Raw expression matrices are not committed. GEO accessions and all derived predictions, fold assignments, selected-feature lists, tables, and figures required to audit the reported results are included in the release.
- Canonical uncertainty outputs are generated by scripts/07_bootstrap_ci.R with pROC and PRROC; the Python cross-check writes separate approximation files and cannot overwrite the submission tables.

The complete session snapshot from the executed analysis environment is archived at results/pilot_gse25055/pilot_session_info.txt. Package declarations are in environment/packages.R.
